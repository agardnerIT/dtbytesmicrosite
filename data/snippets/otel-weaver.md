# OTel Weaver: Your Semantic Conventions Are a Schema — Treat Them Like One

[OTel Weaver](https://github.com/open-telemetry/weaver) is a CLI tool that treats your semantic conventions as a **typed schema you can validate, document, and generate code from**.

Instead of copy-pasting attribute names and hoping they're consistent, Weaver lets teams:

- Define conventions in YAML as a single source of truth
- Generate SDKs, docs, or validation rules from that schema
- Catch attribute drift before it reaches production

> Think of it as **"OpenAPI, but for telemetry attribute naming."**

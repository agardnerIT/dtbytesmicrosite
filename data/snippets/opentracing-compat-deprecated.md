# OTel OpenTracing Compatibility Is Also Being Dropped

If you've been holding on to [OpenTracing](https://opentracing.io/) shims to ease migration, time is running out: OTel is **deprecating its OpenTracing compatibility layer**.

This shim bridges the old OpenTracing API to OTel under the hood — but it will be phased out.

> **Action item:** Teams still using OpenTracing APIs directly should migrate to OTel APIs before the compatibility layer is removed.
